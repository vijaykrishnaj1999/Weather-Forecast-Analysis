**Description**

This Power BI dashboard provides a 7-day weather forecast analysis for major cities worldwide. It visualizes temperature trends, weather conditions, humidity, precipitation, and key weather metrics to help track daily forecasts.

Features
1. **City Temperature Cards**: Quick view of current temp for Athens, Delhi, Lagos, London, New York, Tokyo
2. **7 Days Forecast Table**: Shows Day, Condition, Max Temp, Min Temp, Humidity for the upcoming week
3. **Daily Temperature Sidebar**: Fri, Mon, Sat, Sun, Thu, Tue, Wed with individual temps
4. **Daily Precipitation Trend**: Line chart showing precipitation pattern across the week
5. **Weather Details Panel**: 
   - Sunrise: 06:30 AM
   - Sunset: 08:00 PM
   - Feels Like: 24.0°C
   - Temp: 25.41°C
   - Humidity: 65.07%
   - Wind Speed: 13.72 km/h
6. **Current Time**: Live timestamp display
7. **Condition Icons**: Sunny, Rainy, Stormy, Cloudy visuals

Dataset
Dataset includes daily weather data with fields: City, Date, Day, Condition, Temp_Max, Temp_Min, Humidity, Precipitation, Wind_Speed, Sunrise, Sunset

Tools & Technologies
1. Power BI Desktop (for dashboard design)
2. Power Query (for data transformation)
3. DAX (for calculated measures and KPIs)
4. Excel/CSV/API (for weather data source)

Key Insights
- **Temperature Range**: Weekly max temps range from 28°C to 35°C
- **Weather Variety**: Mix of Sunny, Rainy, Stormy, and Cloudy conditions across the week
- **City Comparison**: Delhi and Lagos show highest temps at ~25.9°C and ~25.4°C
- **Humidity Trend**: Humidity varies from 48% to 81% throughout the week
